Magnet Field Guide — the v10.44 dashboard, element by element

Companion to KING-FIELD-GUIDE.html (the King console is hidden in 10.44 but keeps recording). Everything below is either descriptive (what the field is doing now) or predictive (⚖ hand-set until n≥20 · 📊 measured, re-scored nightly). Nothing else is allowed on the panel.

0. The idea in one paragraph

Nodes are magnets. Each has strength (mass, % of King), polarity (±γ — how contact feels: +γ sticky/pin-prone, −γ wicky/overshoot-prone, drawn purple), a radius (measured pull ≤3 strikes; beyond that 50/50, n=68), and a charge trend (Acm/Dec + %change vs its session open). A magnet's mode is not fixed: it pulls price in, price makes contact (tag / break attempt / blocked by a gatekeeper), then the node deflects and pushes price away. That flip is the tradeable moment. Measured on 4 days / 391 bars (08-11→08-14): the King pulls (55%; 69% at 2 strikes; 74% in the 11am CT hour) and everything else repels (57%; contender ≥60% repels 58%).

1. READ ▸ (top of the panel)

Four lines, every claim with a tag and an n:
👑 King · distance · zone — ORBIT (≤1 strike: price orbits, direction is noise 📊 50%) · PULL (1.5–3: measured pull, cited at your distance and this hour) · OUT (>3: no measured pull). If the King's magnitude is bleeding ≥15% the line says so — a bleeding King far from price stopped pulling on 08-13 (37%).
Range Flr–Ceil — inside/OUT, then each boundary's state (Acm/Dec/Steady), its live episode (Pull / Push / at node / quiet), and how often walls in that state held over 30m (📊 Acm 85%, Steady 80%, Fading 77%).
Non-King mass lean — where the non-King mass sits within 3 strikes; price tends to move away from the heavier side (📊 57%).
Regime — CHOP / MIXED / TREND from the last 20 bars' efficiency ratio. In chop, fade the range edges; trend/confluence calls were contrarian on chop days.
Provenance line: which store the rates come from (08-15 baseline until your local repository has run once) · "re-run now" recomputes.

2. ⚡ Deflections

Confirmed reversals off nodes (tap → sustained move away), with strike, direction, time, and how the outcome scored. This is the event log the episode engine emits into — a deflection is the moment a magnet flips from pull to push.

6. 🧪 Testing tab (shipped in 10.45)

A third tab beside Dashboard and Analysis. It reads the same IndexedDB repository and does one job: measure the past. Every rate carries an n; nothing here predicts. Five blocks.
① Question library. The findings from §5 as live rate bars — King pulls 30m, King pull at 2 strikes, King pull 11am CT, non-King mass repels, contender ≥60% repels, Acm wall reached / leak rate, net-force — each with %, n, and a ⚖/📊 tag. The numbers come from the study store (studyLoad, computed by studyRun); you see the 08-15 baseline until your local repository has run once.
② Hypothesis builder. Preset recipe chips — e.g. King PULL zone · 11am → toward King, Regime CHOP → up? — each compose a WHEN→outcome query over the repo and print rate vs baseline with the lift. Click a chip to run it. For ad-hoc questions use the console API: window.__gptsHypo({when:[{f:'kzone',v:'pull'}],outcome:'toward'}) — when is a list of factor/value filters, outcome is the label to score.
③ Pattern miner. studyMine() auto-scans every single and pairwise factor bucket (kzone, kside, hour, regime, nearest-node state, nearest-node strong/weak) against the outcome, keeps buckets with n ≥ 30, ranks by lift, and shows the combos-tested count. Treat rows as leads ⚖, not laws — with that many combinations some top by chance, so they only earn 📊 after surviving the nightly re-runs. Results cache in localStorage gpts_mine_v1.
④ Insights & recommendations. A rule engine over the study, sorted into four buckets: what the data says · change the product · improve the testing · hypotheses to test next.
⑤ Data coverage strip. Read it top-down before trusting any rate: days · bars · symbols, and which fields exist and since when (via repoCoverage) — a finding that leans on a field only recorded for two days is thinner than its n suggests. The nightly LLM review reads the same store, so the tab and the review agree.
