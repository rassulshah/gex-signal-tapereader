Today both MUD cells show a duration — the same number as MUDt, so the strip had one duration twice and no size for the move. The spec (09-12, §10.2) says MUD = the move, MUDt = its duration. The move is the markup / markdown leg MUDt times: from the open being reclaimed to the 2nd extreme — |2nd extreme − open|. Friday: HOD 7720 − open 7712 = 8.3 points, $413 (green: a markup after a first LOD, as the colour rule already says). The E row uses the expected candle: |expected 2nd extreme − open| = 23.9 points, $1,197. The A row is measured from the chart's own bars (its RTH open and its 2nd extreme), like the HOD / LOD prices already are, so it is right on the contract you trade whichever tab is recording.
