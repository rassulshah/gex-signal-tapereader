What changes

GroupingSettings that belong together sit together. Today the Top node rows are split across the bottom, "Band height" sits beside the SPY width, and the King line style sits next to "Extend".
Shorter namesInside a section the section name is dropped: "King line style" → Style under KING LINE, "Top node line style" → Line style under TOP NODES. "Node bands (first-seen bar to now, polarity colour)" → Draw top nodes.
FixedThree settings whose labels are cut off or missing in your screenshot: SPY rail width ("SPY rail width px (Book =" with no box), the IF line style (a "Solid" box with no name) and the Labels at box (a "Left" box with no name). They now fit.
Width"Width px" becomes SPX rail width px, next to the SPY one.
Mag"Mag line (IF Magnet)" joins the IF level tick boxes as Mag.
Section titlesThe blue headings need a text-only row in the dialog. In 0.6x one of those shifted every setting below it, so I would test it first on a copy. If IRT still shifts them, the sections are kept apart by order and a blank gap instead.

The one cost

IRT saves your settings by row position, which is why rows have only ever been added at the bottom. Reordering them means a new settings version, and your chart opens once with the plugin's defaults. To make that invisible, the new defaults are your current settings (the values in this mockup, taken from your screenshot), so the chart should open looking the same. The only value I can't see is the SPY rail width (its box is cut off). I've used 120, the default.
