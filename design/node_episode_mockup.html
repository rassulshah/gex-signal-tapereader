The LLM sees the full episode log + scorecard each night and must answer three questions: why did each push/hold happen (mechanism, in Academy terms) · what conditions preceded it (candidate predictors) · what to change (window sizes, thresholds, new buckets). Recommendations land in the Analysis tab next morning — the same closed loop the projection system already runs.
The sharpening loop, end to end: live engine labels episodes → per-bar records with conditions at contact → nightly scorecard buckets (including the PREDICT-PUSH arm) → LLM reasoning + recommendations → thresholds/windows tuned → better live labels tomorrow. Nothing is discarded: even failed predictions are scored, because the misses are what sharpen the predictor.
