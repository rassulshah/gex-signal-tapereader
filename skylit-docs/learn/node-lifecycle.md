# Node Lifecycle (skylit.ai/learn/node-lifecycle) — captured 2026-08-13

## Four Stages
- FRESH: untested, price hasn't touched. Full strength, max probability (~80% 1st tap). Target these.
- TESTED: one interaction, price pulled back, level held but positioning partially absorbed (~66% 2nd tap).
- DELIVERED: rejected and moved away — did its job, confirms it was real. Obligation partly/fully satisfied (~33% 3rd tap).
- DECAYING: influence weakens over time with NO interaction — positioning rolling off or price moved away. "Quiet death."

## Core Rule
Do NOT target used levels. Target FRESH positioning. Tested-twice/delivered-once node = "graveyard".

## Real Nodes vs Hedge Nodes  (KEY for our detectors)
- HEDGE NODE: usually far OTM, large & visually dominant, but PROTECTIVE (tail-risk insurance). Not directional intent.
  Does NOT grow; FADES over time. A node big yesterday & smaller today = hedge bleeding off. FADE the bleeders.
- REAL NODE: directional intent, near or far. Defining tell = it GROWS / ACCUMULATES magnitude over sessions.
  Growth = intent. Decay = protection. Trade the growers.
- Practical test: compare a large node across 2-3 consecutive sessions. Bigger = target. Smaller = noise.

## Stairstepping
Price delivers from one FRESH node to the next fresh node in sequence. Each step = a delivery confirmation.
Clearest signal of REAL trend formation. Staircase ends when next level shows no growing positioning.

## Checklist before targeting any node
1. Is it FRESH? (touched before? delivered already? -> downgrade)
2. Is it GROWING? (magnitude across sessions rising = real intent; flat/declining = protective/irrelevant)
Both yes -> valid target. Either no -> find another level.
