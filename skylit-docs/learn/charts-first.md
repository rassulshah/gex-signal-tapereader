# Charts First: Market Structure Before Exposure (skylit.ai/learn/charts-first) — captured 2026-08-13
## THE FOUNDATIONAL DOCTRINE OF SKYLIT ACADEMY.

"Without chart structure, exposure data becomes noise."
Heatseeker is a CONFIRMATION tool, NOT a signal generator. Chart creates the thesis; exposure confirms or DENIES it.
X-ray analogy: doctor forms hypothesis from symptoms FIRST, then X-ray confirms. Chart = assessment, Heatseeker = X-ray.

## 4-Step Workflow (in order, never skip)
1. IDENTIFY STRUCTURE — where is price? significant levels? trend? support/resistance zones, recent reaction levels.
2. FORM A THESIS — specific: "price rallies from this support back to resistance" (NOT "looks bullish").
3. CHECK HEATSEEKER — does dealer positioning ALIGN? +gamma node at entry level = confirm. -gamma cluster through it / no node = deny.
4. EXECUTE OR PASS — chart + exposure same direction = trade. Contradiction = WAIT (the contradiction is itself information).

## Range Extremes vs No-Man's-Land
Middle of a range = trades go to die (equidistant, coin flip w/ costs). Reactions happen at EXTREMES (asymmetry: tight stop one side, room other).
Must know where extremes are BEFORE reading exposure, else you can't tell edge from nowhere.

## Key implication for OUR TOOL
The tool must never present a node as a standalone "trade". A node is only actionable in the context of chart structure
(range extreme, prior reaction level, trend). Big node in mid-range = structurally useless. Same node at a twice-rejected extreme = A+.
