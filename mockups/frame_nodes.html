The Rug / Gatekeeper / King detectors in this codebase all run on the SKYLIT ladder — SPY strikes, %King, isKing/isGatekeeper. The FRAME piles run on InsiderFinance's SPX dte0 profile. Measured minutes ago, the two books do not even agree where the King is:

Sixteen points apart. Tagging an IF pile "RUG" using geometry computed on Skylit levels would attach a verdict to a level it was not computed from — the exact book-mixing this project banned after the 113× magnitude discovery.
