Badge colours — the one call I want to flag

Chips are coloured by what it means for price, not by the node's polarity:
· green = bullish for price — support building, or resistance failing
· red = bearish for price — resistance building, or support failing
· grey = no decisive change

So a yellow call node can carry a green chip when it is dissolving, because a dying ceiling is bullish. Polarity is already told by the price colour; the chip is free to answer the actual question, which is which way price goes. If you would rather the chip match the node colour, say so — but then two elements say the same thing and nothing says where price is heading.
