Behaviour

• Only one can hold the panel at a time — opening ⧉ closes an open PiP, and vice versa. The panel is a single DOM node, so it lives in exactly one place.
• The window remembers its size and position in localStorage and reopens there.
• The grip disappears in both pop-outs: the panel fills its window and the OS window edge does the resizing. The grip stays for the in-page panel, where it works.
• Atlas must stay open either way — it is what captures the feed — but it no longer has to be the visible tab. panelVisible() gets extended to count an open ⧉ window, or the ladder would silently stop refreshing whenever you looked away from Atlas.

Also removed

The grey pop-out grip. Chrome reverts every height change to a PiP window — measured five times, asked=713 → settled=693 (reverted) — so it is a handle that cannot work. Leaving it there is a button that lies.
