Rules

One read: head line (direction word · grade · session) then ONE paragraph — leg sentence (your 15, unchanged) → structure sentence → caveat. No "Map:" label, no separate ⚑ line.

The bar a pullback node lands: the read takes the ⚑ style (red for a down leg, green for up) and the leg sentence carries the banner's detail ("— rolled lower from X · 2nd step, signal"). Next bar it reverts.

No repetition: if the leg sentence already names the pullback node (handoff, formed, pulling back, deflected), the structure sentence drops its "Pullback node likely at" clause. If both would name the magnet, only the leg sentence does.

Twelve structure sentences (ceiling/floor rolling down/up, both down/up, compression, expansion, converging, middle emptying, magnet moving, holding); "dissipated" for gone, "dissipating" for dec; acm/dec words stay green/red.
