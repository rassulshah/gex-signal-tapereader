How the pieces behave: the folder is picked ONCE (the handle persists) — point it inside Google Drive desktop and FlexLevels picks the file up from the synced copy; the panel silently rewrites it on the cadence. A market's ratio goes LIVE whenever that chart + tape pairing is on screen (the same futures-basis capture ES uses today), is cached with the ~ tag otherwise — the tilde is also appended to those rows' labels inside IRT, so a level from a stale ratio announces itself — and can be typed manually for a book the panel has never seen paired. GC/CL rows need their books flowing: GLD/USO join the background self-fetch in this build, so their levels refresh without the chart being on them. Unchecked markets write nothing. ⓘ carries all of this. Also in v14.8, invisible here: the chart-flip guard — an unrecognized chart symbol (GLD, USO, anything) PAUSES recording with a visible note instead of writing foreign candles into the SPY book.
