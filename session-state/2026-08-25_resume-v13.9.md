## Learned this build
- **The v13.8 push polluted the repo**: ~20 old downloaded installers landed in `mockups/` via
  `git add -A`, ballooning the v13.9 installer to 30MB and hanging its own extraction (`more +n` on
  390K lines). Builder now excludes `.bat` from payload dirs, caps the payload at 6MB loudly, and
  the installer purges `mockups/install*.bat` on the user's machine before committing. If a future
  installer is ever >>2MB, look for repo pollution FIRST.
- A pin against wobble is only as good as its capture — persisted state can poison a guard silently.
  The heal pattern: disagree persistently ⇒ re-pin loudly, never per-render.
- The latch counts per CLOSED BAR, not per render/scan — any counting rule enforced in render code
  would inflate with redraw rate.
- Live-mitigation first, permanent fix second worked well: localStorage `gpts_emopen_v1` rr was
  hand-patched to the live ratio before the build shipped, so the operator's rail was right within
  a minute of the report.
