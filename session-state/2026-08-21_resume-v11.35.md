## ⚠ READ FIRST — TWO THINGS THAT EXPLAIN MOST OF THIS PROJECT'S BUGS

**1. Mislabeling.** Every significant defect this session was the same shape: *a number displayed under a
label implying a different source, window, or scale than it actually had.* The ladder said `IF` and
rendered Skylit numbers. `week` said "to Fri" and held one expiration. `DRIFT ✓` sat beside "both books
not in yet". The playbook said "breaks not fades" directly above "fades work". None of them threw.
**Ask of every number on the face: which book, which window, which scale — and does the label say so.**

**2. Moving denominators.** %King is right for ranking at one instant and WRONG for comparing two
moments — if the King strike changes, every node's percentage rebases at once. Anything measuring
change over time must use DOLLARS. This has now bitten three separate features.

## ROLL DETECTION — BUILT in v11.34 (`rollDetect`), still SHADOW MODE

**User's definition, which is better than my first proposal:** a roll is **mass transferring between
strikes** — one node dissipating while another on the same side accumulates. NOT "the nearest node above
price stepped". Their examples: ceiling 7716→7705, floor 7674→7685.
Mockup: `/tmp/mock2/roll-mockup.html`. Node-chart preview: `/tmp/node-chart-preview.html`.

### Calibration — MEASURED, not guessed (from today's 390 snapshots × 209 strikes, 1-min cadence)
| parameter | value | why |
|---|---|---|
| window | **30 min** | sweep: 15m/20m/45m all worse-behaved |
| threshold | **50%** | 35% → 37 events/session (noise); 70% → 2 (silence); 50% → 9 |
| baseline | **subtract the session median change** | the median near-money strike GROWS 10–15% per 30m; without this everything "accumulates" in the morning and "dissipates" into the close |
| min size | **$40M** | archive median node is $81M, p25 $31M |
| reach | **±5 strikes** | |
| pairing | dissipating + accumulating, **same side of price** | |
| display | one ceiling roll + one floor roll max | 132px chart |
| no partner | fade the row, **no arrow to nowhere** | a wall evaporating is not a roll |

Expiry-day decay swamps everything in the last 30–45 min (strikes lost 75–94% today). The median
subtraction handles it; without it the detector screams into every close.
