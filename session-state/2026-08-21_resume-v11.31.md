### The ladder reads InsiderFinance, on SPX, with no fallback
- Companion fetches **SPX** (`SYMS=['SPX','QQQ']`), not SPY. **ES is a future ON SPX.**
- Conversion is a **live basis** (~1.003) from THEIR spot vs the futures print — not a ~10.05 multiplier.
  A half-point of disagreement used to arrive on the chart as five ES points.
- **THREE SCALES, and each consumer must use the right one.** Every row carries:
  - `k`    — their original strike (SPX)
  - `disp` — chart scale (ES), for display
  - `und`  — underlying scale (SPY), **for the candle reads**, because `closedCandles` divides futures
    candles back down. The rejection detector, ATR and the zone width all run on `und`. Using `disp`
    there compares ES prices against SPX levels and the detector silently never fires.
- `ifNum()` formats values ALREADY on the chart scale. **Do not pass them to `fmtLvl`/`fmtSpan`** —
  those convert FROM the underlying and would apply the ratio twice.
- **NO SILENT FALLBACK** (user-directed). Missing or >25 min stale → the ladder says so and shows nothing.
  Skylit's levels are one call away and that is exactly why they are not substituted.

### The Friday roll — and why it oscillated
`exp_mode=week` means "through Friday of the current week", which ON a Friday is today, so the week
window collapsed onto 0DTE and CR/CR0 printed the same number off the same 284 strikes.

v11.27 rolled it forward. **v11.28 fixed the roll fighting itself**: `expSetRollCheck` re-tested the
HELD week set every tick, so once the rolled window came back with six expirations it no longer looked
collapsed → roll dropped → next fetch unrolled → collapsed → re-armed. The panel flipped between
288 strikes/146 mixed and 284/0 **every cycle**. Whether your levels were right depended on when you
looked.

> **A roll is a property of the DATE, not of the set you happen to be holding.** Do not infer a
> condition from data that the fix itself modified.

The companion carried the identical bug (`friday === today`) and was fixed the same way in v1.1.

### Also live
- **2D regime** (GEX × VEX) — `−γ/−V` gets ⚠ self-reinforcing and switches the playbook to momentum
  with widened stops. We were receiving both books and using half.
- **Session phase** — expiry flagged from the OPEN, not from 13:30. Phase text describes CONDITIONS
  only; fade-vs-break belongs to the regime line alone, and a test greps every phase string for
  tactical language so the contradiction cannot come back.
- **Price action instead of internals** — no TICK/ADD/cumulative delta exists, so PA is close location
  `(c−l)/(h−l)` plus HH/HL structure. **Structure breaks the tie** when close location lands mid-band
  (live: LH/LL at 0.42 was voting neutral).
- **Rejection detector** requires price to have COME FROM the side it closes back to. Without that a
  bar straddling the level satisfies both patterns and a clean BREAK reads as a REJECTION.
- **ACCUM abstains on purpose** when every wall is tape-derived (`abs`/`net` null, only %King) — summing
  dollar mass off a moving percentage denominator is the error this project already ruled out. It now
  says why instead of printing a bare dash.
